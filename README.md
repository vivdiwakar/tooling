# Tooling
Linux OS and Dev helper tooling

- `elixir-sys-installer.sh`:
  - Checkout Elixir source - `git clone -v git@github.com:elixir-lang/elixir.git`
  - `cd elixir`
  - Copy `elixir-sys-installer.sh` to top-level inside `elixir` directory
  - Run `sudo ./elixir-sys-installer.sh vxx.yy.zz` - this will build and install everything
